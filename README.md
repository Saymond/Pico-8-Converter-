# 🎮 Pico-8 Converter

**.p8 ↔ .p8.png** cartridge converter for Android.

---

## ✨ Features

- 🔄 Convert `.p8` text carts to `.p8.png` image carts and back
- 🖼️ Custom cartridge label image support (128×128 PNG)
- 💾 Export result via system file picker
- 🎨 Material You design with dark/light theme
- 📴 No internet required — fully offline

## 📱 Usage

1. **📂 Pick** a `.p8` or `.p8.png` file
2. Optionally **🖼️ Pick a label PNG** for custom cartridge art
3. Tap **⚡ Convert**
4. **💾 Export** the result to any folder

## 📋 Requirements

- Android 7.0+ (API 24)
- arm64-v8a
